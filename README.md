# creator-of-electrical-circuit-boards
## Задача полученая на практике. Выполняют Давыдов А.Ю. и Южаков Ф.А.
# 1. Цель
Разработать программное обеспечения, обеспечивающего полуавтоматический цикл изготовления печатных плат на фрезерном станке с ЧПУ. Целевой пользователь – радиолюбитель или мелкосерийный производитель, работающий с ручными или простыми графическими редакторами. ПО должно минимизировать ручные расчёты, исключить ошибки привязки координат и автоматизировать генерацию управляющих команд.

# 2. Функциональные требования

## 2.1. Распознавание и привязка заготовки (Machine Vision)
- Захват изображения рабочей зоны с помощью камеры, установленной над станком.
- Автоматическое определение границ, ориентации и положения заготовки (текстолита) в поле зрения.
- Коррекция рабочей системы координат станка относительно реального положения заготовки.
- Визуальное подтверждение привязки в интерфейсе с возможностью ручной подстройки.

## 2.2. Импорт исходных данных
- Поддержка форматов:
  - `PNG` / `BMP` (растровые маски топологии)
  - `Gerber RS-274X` (стандартный формат слоёв печатных плат)
- Валидация файлов, автоматическое определение масштаба (мм), проверка на разрывы контуров и артефакты.
- Разделение слоёв (топология, паяльная маска, шелкография, отверстия) при импорте Gerber.

## 2.3. Обработка и генерация траекторий
- Векторизация растровых изображений (пороговая обработка, сглаживание, преобразование в полилинии).
- Расчёт траекторий с учётом:
  - Диаметра фрезы и компенсации на радиус инструмента
  - Глубины прохода, подачи, скорости вращения шпинделя
  - Стратегии обработки (внешняя/внутренняя обводка, зигзаг, спираль)
- Генерация корректного `G-кода`, совместимого с распространёнными контроллерами.
- Предварительная симуляция и проверка на столкновения/выход за пределы заготовки.

## 2.4. Визуализация и разметка расположения
- Наложение рассчитанной топологии на изображение заготовки в интерфейсе.
- Опциональная фрезеровка для контроля совмещения.
- Вывод предварительного отчёта: площадь обработки, время цикла, требуемые инструменты.

## 2.5. Последовательное выполнение операций
- Строгое соблюдение технологической очереди:
  1. **Сверление отверстий** (металлизация/монтажные, с учётом диаметров)
  2. **Фрезеровка дорожек** (удаление меди по контуру топологии)
  3. **Нанесение текста/маркировки** (гравировка)
  4. **Контурный вырез** (отделение платы от заготовки)
- Возможность паузы, ручной смены инструмента с подсказками в UI.

# Этапы разработки
| № | Название этапа | Материальный тестированный результат |
|:--|:---|:---|
| **1** | Ядро обработки данных (Импорт → Векторизация) | Загруженные файлы → единая внутренняя модель векторов; скриншот «растр → вектор» с нзкой погрешностью |
| **2** | Расчёт траекторий и генерация G-кода | Готовый `.gcode`/`.nc`; отчёт симулятора (время, площадь, проверка выходов за габариты); скриншот превью траекторий |
| **3** | Калибровка и алгоритмы машинного зрения | Матрица калибровки; скрипт детекции; отчёт точности привязки при ≥5 тестовых положениях |
| **4** | UI-интеграция и визуализация рабочего процесса | Рабочий интерфейс; скриншоты с наложенной топологией; сгенерированный отчёт (время, инструменты, площадь) |
| **5** | Физическое тестирование и отладка параметров | Фото/видео готовой тестовой платы; таблица оптимальных параметров резания; отчёт о прохождении всех 4 этапов без вмешательства оператора,за исключением запуска и смены оснаски |
